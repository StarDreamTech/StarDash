# 星盘 0.1.0 本机验证

日期：2026-11-17。环境：Apple Silicon arm64，macOS 27.2.1，Swift 6.4.2。

## 构建与核心检查

- `./scripts/build.sh`：release 构建成功，应用组装完成，本地临时签名及严格签名验证通过。
- `--self-test`：16 项计算、异常边界及本机采集检查通过，覆盖 CPU 增量／溢出、网络时间间隔／接口重置／新增接口、倒计时／单位格式及本机采集。
- `--diagnostics`：真实 CPU、内存、网速、内置电池与供电采集成功，错误集合为空。
- `--power-test`：系统实际防休眠断言创建成功；主线程暂停期间系统仍按时关闭断言；到期、手动结束与重复清理通过。

防休眠检查通过 `pmset -g assertions` 核对测试进程实际持有的系统断言，不仅检查应用内部变量。系统超时后属性副本仍可能保留创建时的级别，因此不以该属性作为生效依据。

## 界面实测

- 悬浮窗口真实显示四组指标，精简／展开随内容调整大小。
- 置顶／取消置顶成功，窗口层级随开关改变。
- 开始防休眠后出现倒计时与结束按钮；切到精简模式后仍显示并能结束。系统断言在开始时存在、结束后释放。
- 在“显示项目”关闭内存后卡片消失；退出并重新打开，内存仍隐藏，精简、置顶、悬浮形态及拖动后位置均恢复。
- 最后恢复四项显示、展开、不置顶、防休眠关闭；保留悬浮窗口供本机体验。
- 从悬浮窗口切到菜单栏面板，已截图核对布局与真实指标。验证工具未能将该弹出面板绑定到对应的辅助功能窗口，因此面板内控件未完成自动化逐项回归；未绕过工具的窗口绑定限制。

## 未验证或未完成

- 最低 macOS 13 仅为项目声明；Intel、其他 macOS、多屏、全屏和长期资源占用未验证。
- 无电池和采集失败的显示分支已有实现，但未在相应硬件／实际故障环境复测。
- 本机电池为满电接电状态，未逐项测试放电与充电切换；网络也未逐项测试所有外接网卡／VPN 组合。
- 未进行 Apple 开发者签名、公证、自动更新、全局快捷键或图标收纳。

生成了 `.build/`、`build/StarDash.app`，以及工作目录 `outputs/` 中的 ZIP、文档副本和界面截图。GUI 验证写入星盘自己的 UserDefaults 和窗口位置。防休眠任务已经结束，未留下星盘电源断言；未运行旧收纳原型，也未安装到 Applications。
