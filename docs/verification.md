# 星盘本机验证

日期：2026-11-17。环境：Apple Silicon arm64，macOS 27.2.1，Swift 6.4.2。

## 0.2.0 命令快捷图标

- release 构建、本地临时签名及严格签名验证通过；本机 SDK 同时提供同名 State 宏和属性包装器，界面通过类型别名明确使用属性包装器，兼容现有 Command Line Tools。
- 原有 16 项自检通过；新增命令自检覆盖空名称／空命令／空字符拒绝、名称清理、图标回退、添加／编辑／删除／重启恢复、损坏数据不覆盖。
- 实际调用 zsh 验证中文、单双引号、空格、管道及多行命令，字面量 `$HOME`、`$(...)`、反引号未被额外展开，含单引号的目录正确，非零退出码保留。
- 临时脚本权限为 0700，实际开始执行后脚本及其专属目录删除；自检临时目录及独立 UserDefaults 测试域均清理。
- 悬浮窗口实测：新增命令、选图标、保存后出现图标；保存时未产生输出文件，点击图标后系统终端打开并执行。
- 终端实际输出“星盘命令验证：it's working”，随后输出用户主目录，诊断结果文件内容一致；终端显示进程已完成。未触发自动化授权请求。
- 右键编辑名称和图标成功；退出并重新启动后名称、图标、命令仍在。右键删除会弹确认，取消保留图标，确认删除后恢复空状态；重新启动最终构建仍为空状态，测试命令已从真实配置移除。
- 截图核对命令区和编辑窗口的完整布局。菜单自动化的跨次等待会使临时菜单目标失效，连续执行右键、选择、确认完成验证；未修改系统权限或浏览器配置。

本轮未对菜单栏弹出面板内的新命令按钮逐项自动化回归，仍复用与悬浮窗口相同的视图、模型和执行路径。大量命令滚动、最低 macOS 13、Intel、交互式 sudo 与长时间命令未专项实测。0.2.0 未重跑与此改动无关的系统防休眠测试，沿用下文 0.1.0 记录。

本轮产生 `.build/`、`build/StarDash.app`、0.2.0 ZIP、界面截图及 `outputs/stardash-command-result.txt`。GUI 测试写入星盘自己的命令配置，测试条目已删除；终端保留完成后的输出窗口及系统正常生成的会话／历史记录。未安装到 Applications。

以下为 0.1.0 的验证记录。

## 构建与核心检查

- `./scripts/build.sh`：release 构建成功，应用组装完成，本地临时签名及严格签名验证通过。
- `--self-test`：16 项计算、异常边界及本机采集检查通过，覆盖 CPU 增量／溢出、网络时间间隔／接口重置／新增接口、倒计时／单位格式及本机采集。
- `--diagnostics`：真实 CPU、内存、网速、内置电池与供电采集成功，错误集合为空。
- `--power-test`：系统实际防休眠断言创建成功；主线程暂停期间系统仍按时关闭断言；到期、手动结束与重复清理通过。

防休眠检查通过 `pmset -g assertions` 核对测试进程实际持有的系统断言，不仅检查应用内部变量。系统超时后属性副本仍可能保留创建时的级别，因此不以该属性作为生效依据。

## 界面实测

- 悬浮窗口真实显示四组指标，精简／展开随内容调整大小。
- 置顶／取消置顶成功，窗口层级随开关改变。
- 开始防休眠后出现倒计时与结束按钮；切到精简模式后仍显示并能结束。系统断言在开始时存在、结束后释放。
- 在“显示项目”关闭内存后卡片消失；退出并重新打开，内存仍隐藏，精简、置顶、悬浮形态及拖动后位置均恢复。
- 最后恢复四项显示、展开、不置顶、防休眠关闭；保留悬浮窗口供本机体验。
- 从悬浮窗口切到菜单栏面板，已截图核对布局与真实指标。验证工具未能将该弹出面板绑定到对应的辅助功能窗口，因此面板内控件未完成自动化逐项回归；未绕过工具的窗口绑定限制。

## 未验证或未完成

- 最低 macOS 13 仅为项目声明；Intel、其他 macOS、多屏、全屏和长期资源占用未验证。
- 无电池和采集失败的显示分支已有实现，但未在相应硬件／实际故障环境复测。
- 本机电池为满电接电状态，未逐项测试放电与充电切换；网络也未逐项测试所有外接网卡／VPN 组合。
- 未进行 Apple 开发者签名、公证、自动更新、全局快捷键或图标收纳。
